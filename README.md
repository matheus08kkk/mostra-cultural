
# Calculadora em Python

## Descrição do Projeto

Este projeto consiste no desenvolvimento de uma calculadora
simples utilizando a linguagem de programação Python.

O programa permite realizar operações matemáticas básicas,
como adição, subtração, multiplicação e divisão.

## Objetivo

O objetivo deste projeto é praticar conceitos fundamentais
da programação em Python, incluindo:

- Variáveis;
- Entrada e saída de dados;
- Estruturas condicionais;
- Funções;
- Operações matemáticas.

## Funcionalidades

- Realizar adição (+);
- Realizar subtração (-);
- Realizar multiplicação (*);
- Realizar divisão (/);
- Identificar operações inválidas;
- Evitar divisão por zero.

## Tecnologias Utilizadas

- Python 3

## Como Executar

1. Instale o Python 3 em seu computador.
2. Faça o download do arquivo script.py.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```bash
python script.py
```

## Exemplo de Execução

```text
===== CALCULADORA EM PYTHON =====
Digite o primeiro número: 10
Digite a operação (+, -, *, /): +
Digite o segundo número: 5

Resultado: 15.0
```
